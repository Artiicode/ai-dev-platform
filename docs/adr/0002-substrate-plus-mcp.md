# ADR 0002 — 모델-무관성: 파일 기판 + MCP 어댑터(둘 다, 계층형)
- 상태: accepted · 날짜: 2026-06-08
## 맥락
"어떤 AI든 기여" 요구. 단일 하네스는 플랫폼마다 실행층(slash command/hook/MCP)이 달라 불가능.
## 결정
파일 컨벤션 기판을 진실 원본(의존성0·git친화·보편접근)으로, MCP 서버를 같은 기판의 고충실도
접근 어댑터로 그 위에 올린다. 플랫폼 특수성은 adapters/ 의 얇은 어댑터가 흡수.
## 대안
(a) 파일만 — 시맨틱/SQL 질의 비효율. (b) MCP만 — 미지원 클라이언트 배제, 서버 장애 시 접근 불가.
## 결과 (ARCHITECTURE §1)
보편 baseline + 지원처 가속을 동시 확보. 데이터 소유권은 L2 기판으로 단일화.
